# FastClick ⚡

Платформа для обучения слепой десятипальцевой печати. Чистый HTML/CSS/JS, без сборки и зависимостей: откройте `index.html` через любой статический сервер.

## Возможности

- **Курс** - 14 этапов для русской и 16 для английской раскладки (116 упражнений): от домашнего ряда до свободной печати. Буквы вводятся постепенно, уроки строятся только из уже изученных клавиш. Заглавные (Shift), знаки препинания, цифры. Три звезды за точность и скорость; следующие упражнения открываются по мере прохождения.
- **Две раскладки** - ЙЦУКЕН и QWERTY.
- **Подсказки** - экранная клавиатура с подсветкой следующей клавиши, цвета пальцев, схема рук, подсказка про нужный Shift.
- **Ввод по положению клавиш** - можно учить русскую раскладку при включённой английской в системе (и наоборот). Отключается в настройках для Dvorak/Colemak.
- **Тест скорости** - 30 с / 1 / 3 / 5 мин; слова (с заглавными, знаками, цифрами), связный текст, предложения; личные рекорды, график скорости по секундам.
- **Практика** - готовые тексты, **слабые клавиши** (приложение само находит, где вы чаще ошибаетесь или медлите) и **свои клавиши** (выберите их кликом по клавиатуре).
- **Игра «Метеориты»** - падающие слова.
- **Статистика** - графики скорости и точности, календарь активности, тепловая карта ошибок и медленных клавиш, 15 достижений, серия дней, дневная цель.
- Режимы ошибок: строгий (курсор ждёт верной клавиши) и классический (с Backspace). Скорость в зн/мин или сл/мин.
- Светлая/тёмная тема, звуки (по желанию), доступная навигация, `prefers-reduced-motion`, PWA (работает офлайн).
- Прогресс хранится в `localStorage`, есть экспорт/импорт JSON.

## Запуск

```bash
npm start            # python3 -m http.server 8080 -> http://localhost:8080
npm test             # модульные тесты (node:test, без зависимостей)
```

ES-модули не работают с `file://`, поэтому нужен локальный сервер (подойдёт любой: `npx serve`, `python -m http.server`).

## Публикация

Репозиторий готов к GitHub Pages: включите *Settings → Pages → Source: GitHub Actions* - workflow `.github/workflows/pages.yml` выкладывает сайт при каждом пуше в `main`. Все пути относительные, поэтому сайт работает и в подкаталоге (`user.github.io/fastclick/`).

## Структура

```
index.html            точка входа
css/style.css         тема, компоненты (светлая/тёмная)
js/layouts.js         раскладки, пальцы, разбор событий клавиатуры
js/corpus.js          слова, предложения, абзацы (ru/en)
js/generator.js       генерация текстов упражнений и тестов
js/course.js          структура курса и оценка звёздами
js/engine.js          движок набора (чистая логика, без DOM)
js/store.js           прогресс, статистика, достижения (localStorage)
js/typing.js          компонент тренажёра
js/keyboard.js        экранная клавиатура и руки
js/game.js            игра «Метеориты»
js/views-*.js         экраны; js/app.js - роутер (#/course, #/lesson/ru-1-1, ...)
tests/                тесты ядра
```

## Как это считается

- **Скорость** - «чистые» знаки в минуту (только верные), время от первого нажатия. 1 слово = 5 знаков.
- **Точность** - доля верных нажатий среди всех, включая исправленные ошибки.
- **Звёзды**: 1 - точность ≥ 90%; 2 - ≥ 95% и 70% от целевой скорости; 3 - ≥ 97% и целевая скорость.
- **Слабые клавиши**: доля ошибок и среднее время между нажатиями по каждой клавише (нужно ≥ 8 нажатий).
- Попытки короче 3 с / 30 знаков не учитываются в рекордах скорости.
